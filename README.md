## 🌟 Key Capabilities & Features

### 1. 🎞️ Multi-Track NLE Video Timeline
- **Track Hierarchy**:
  - `V2`: Video & Image Overlay Layer
  - `G1`: Motion Graphics & Typography Layer
  - `V1`: Background Base Layer
  - `A1`: Audio & Procedural Synthesizer Layer
- **Precise Timecode & Scrubbing**: HH:MM:SS:FF at 30/60 FPS.
- **Clip Manipulation**: Draggable clip pills, trimming handles (start/end), split clip at playhead (razor), clip duplication, track mute/solo/lock.
- **Keyframe Motion Diamonds**: Visible keyframe count and markers directly on timeline clips.

### 2. 🎨 Interactive Viewport & Transform Gizmo
- **Visual Transform Gizmo**: Direct on-canvas bounding box, 4 corner scale handles, and top rotation handle.
- **Aspect Ratio Presets**:
  - `16:9` Cinema / YouTube (1920 × 1080)
  - `9:16` TikTok / Reels / Shorts (1080 × 1920)
  - `1:1` Square Social Feed (1080 × 1080)
  - `4:5` Portrait (1080 × 1350)
  - `21:9` Anamorphic UltraWide (2560 × 1080)
- **Layer Blend Modes**: Normal, Screen, Multiply, Overlay, Color Dodge, Luminosity.

### 3. ⚡ WebGL & Canvas Post-Processing FX
- **35mm Film Grain Simulation**: Dynamic animated jitter noise.
- **Chromatic Aberration**: Directional RGB color-channel split.
- **CRT Scanlines & Glitch Twitch**: Retro television scanlines and horizontal distortion.
- **Cinematic Bloom**: Multi-layer glow dispersion.
- **Lens Vignette**: Circular falloff for cinematic depth.
- **Duotone Gradient**: Two-tone split-toning.
- **VHS Retro**: Analog cassette tracking line, jitter, and color bleed.

### 4. 🌈 Color Grading Suite & LUTs
- **Turnkey LUTs**:
  - Teal & Orange Hollywood Blockbuster
  - Cyberpunk Neon Matrix
  - Kinfolk Warm Earth Film
  - B&W High Contrast Noir
  - 1970s Vintage Kodachrome
- **Parametric Sliders**: Exposure, Contrast, Saturation, Temperature (Cool/Warm), Tint (Green/Magenta), Shadows, Highlights.

### 5. 🎵 Procedural Web Audio Synthesizer & Visualizer
- **4 Procedural Music Moods**:
  - *Synthwave*: 120 BPM driving bassline, 4-on-the-floor kick, retro snare, arpeggio.
  - *Kinfolk*: 72 BPM meditative ambient pads, sub drone, wooden bell chimes.
  - *TikTok*: 128 BPM energetic punchy 808 kick, snap, syncopated rhythm.
  - *Lofi Sunset*: 84 BPM warm Rhodes electric piano 7th chords, vinyl crackle, boom-bap drums.
- **Dynamic FFT Spectrum Analyser**: Real-time frequency bars reactive overlay.

### 6. 🤖 Generative AI Studio Simulator
- Visual prompt tags: *Cyberpunk Neo-Tokyo*, *Cinematic Film 8K*, *Kinfolk Minimalist*, *Lofi Sunset*, *Digital Matrix Stream*, *3D Hyperspace Stars*.
- One-click procedural generative scene creation added directly to the timeline.

### 7. 🚀 Turnkey 1-Click Templates
1. **Neo-Tokyo Cyberpunk Trailer** (16:9, glitch shaders, neon typography, synthwave beat).
2. **Kinfolk Organic Moodboard** (4:5, 35mm grain, warm earth tones, serene typography).
3. **Viral TikTok Product Ad** (9:16, kinetic spring motion, sales badges, punchy rhythm).
4. **Lofi Sunset Music Audiogram** (1:1, audio spectrum reactive bars, vintage VHS overlay).

### 8. 🌐 Full Bilingual Interface (العربية / English)
- Instant RTL / LTR layout toggle with comprehensive translations for all controls, tools, tooltips, and timecodes.

## 💻 Tech Stack
- **Framework**: Vite + TypeScript
- **Styling**: Modern CSS Dark Titanium/Cyber Studio Theme
- **Rendering**: HTML5 Canvas 2D + WebGL Pipeline
- **Sound**: Web Audio API (Synthesizers, Noise Buffers, AnalyserNode)

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/Tareq0001/CineMotion-Creative-Studio.git
cd CineMotion-Creative-Studio

# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```
